# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

0.1.x is the only published line. Older releases are not supported.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability reporting. Open a Security Advisory on [Salman-Labs/mcp-dialect-fix](https://github.com/Salman-Labs/mcp-dialect-fix/security/advisories/new).

Do not open a public issue for a security report.

We expect to acknowledge a report within 7 days.
